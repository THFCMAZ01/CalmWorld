# Calm World

A simple mindfulness and wellness website built to make small moments of calm easier to find and practise.

Calm World brings together beginner-friendly daily mindfulness ideas, examples of traditions from around the world, and a collection of free resources. The idea behind the project is straightforward: useful wellbeing information should be approachable, easy to browse, and not hidden behind a sign-up form.

> No ads. No tracking. No login. Just peace.

## Live Demo

[Visit Calm World](https://thfcmaz01.github.io/CalmWorld/)

## A little about the project

This was one of my first websites, built while I was learning the fundamentals of web development. It is a snapshot of that stage of my journey: experimenting with page layouts, shared styling, typography, colours, CSS effects, and building a small multi-page experience from scratch.

I have kept the original visual direction rather than turning it into a completely different project. The site uses a deep-purple colour palette, gradients, translucent panels, blur effects, and subtle hover interactions. I am also working on making the layout more comfortable to use on phones and tablets.

## Pages

| Page | What you'll find |
| --- | --- |
| **Home** | Introduction to Calm World and links to the main sections. |
| **Daily Practices** | Ten simple mindfulness activities that can be tried in everyday life. |
| **World Traditions** | A selection of mindfulness and relaxation practices associated with different places and cultures. |
| **Free Resources** | A list of external mindfulness tools, programmes, and learning resources. |
| **About** | The purpose and guiding ideas behind the project. |

## Built with

- **HTML5** – page structure and content.
- **CSS3** – layout, responsive styling, gradients, glassmorphism-inspired panels, transitions, and hover effects.

There is no application framework or build step. The site is made from static HTML pages that share one stylesheet.

## Run locally

Because this is a static website, you can open it directly in a browser:

1. Clone the repository:
   ```bash
   git clone https://github.com/THFCMAZ01/CalmWorld.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

You can also use a local development server if you prefer. No dependencies need to be installed.

## Responsive layout

The original layout was designed mainly with larger screens in mind. A responsive improvement is being introduced to make the navigation, typography, spacing, and content grids adapt to tablet and mobile screen sizes while keeping the original design identity.

## What I learned

Working on Calm World gave me an early opportunity to practise:

- Structuring a small website across multiple HTML pages.
- Reusing a shared CSS stylesheet for consistent styling.
- Using Flexbox and CSS Grid for page layouts.
- Applying typography, colour, gradients, shadows, and blur effects.
- Adding hover and transition effects.
- Thinking about accessibility basics, including viewport settings and keyboard focus.
- Revisiting an early project and improving its responsiveness without losing its original character.

## Future improvements
